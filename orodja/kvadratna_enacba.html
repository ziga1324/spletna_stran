Reševalnik kvadratne enačbe

Vnesi koeficiente enačbe ax² + bx + c = 0.

Kako deluje?

Diskriminanta: D = b² − 4ac.

Če je D > 0, sta dve realni rešitvi. Če je D = 0, je ena dvojna realna rešitev. Če je D < 0, sta dve kompleksni rešitvi.

Formula: x = (−b ± √D) ÷ (2a).

Primer: x² − 5x + 6 = 0 ima rešitvi x = 2 in x = 3.

Če je a = 0, orodje reši preostalo linearno enačbo.
