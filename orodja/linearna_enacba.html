Reševalnik linearne enačbe

Vnesi koeficiente enačbe ax + b = c.

Kako deluje?

Od obeh strani odštejemo b: ax = c − b. Nato obe strani delimo z a: x = (c − b) ÷ a.

Primer: 2x + 3 = 11 → 2x = 8 → x = 4.

Če je a = 0 in b = c, je rešitev vsako realno število. Če je a = 0 in b ≠ c, enačba nima rešitve.
