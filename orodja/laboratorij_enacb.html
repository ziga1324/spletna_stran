Poglej enačbo

y = ax + by = c

Premakni drsnik ali kazalec po grafu. Na telefonu se grafa dotakni. Merili osi sta lahko različni; za vrednosti uporabi oznake osi in spodnji izpis.

Od enačbe do rešitve

    Preverjanje z vstavljanjem in tabela vrednosti

    x ax + b c

    Kaj ti pove graf?

    Linearna enačba: presečišče dveh premic

    Pri ax + b = c iščemo x, za katerega imata funkciji y = ax + b in y = c enako vrednost. Če je a ≠ 0, se sekata natanko enkrat. Če je a = 0, premici bodisi sovpadata bodisi sta vzporedni in različni.

    Kvadratna enačba: ničle parabole

    Pri ax² + bx + c = 0 iščemo presečišča z osjo x. Za a ≠ 0 pove diskriminanta D = b² − 4ac, ali ima enačba dve različni realni rešitvi (D > 0), eno dvojno realno rešitev (D = 0) ali dve kompleksni rešitvi (D < 0). Kompleksnih rešitev ne označujemo na realni osi x.

    Če je pri kvadratnem zapisu a = 0, ostane linearna enačba bx + c = 0. Računanje poteka v brskalniku, brez pošiljanja koeficientov strežniku. Rezultati in graf so numerični približki, ne simbolni dokaz.
